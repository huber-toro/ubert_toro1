
# Evidencia de Actividad #3  
**Uso de manejo de datos utilizando Pandas**

- **Materia:** Analítica de Datos

- **Institución:** Institución Universitaria Digital de Antioquia  
- **Año:** 2026  

## Descripción del proyecto  
Este proyecto corresponde a la Evidencia #3 del curso de Analítica de Datos.  
El objetivo es aplicar herramientas de **Pandas** para:  
- Explorar y comprender la estructura de un dataset de libros.  
- Realizar limpieza y filtrado de datos.  
- Desarrollar análisis estadísticos básicos.  
- Visualizar resultados mediante gráficos.  
- Redactar conclusiones integrando todas las fases del análisis.
